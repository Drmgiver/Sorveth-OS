# ADR 0002 — User-owned resources and optional Sorveth Mind

**Status:** Architectural principle accepted, not yet implemented, 2026-10-22.

- Native applications expose non-executable user-facing assets through a common,
  documented and editable resource system. The OS itself follows this contract.
- Capabilities and native actions are discoverable and structured, never magical
  rights inferred from a natural-language command.
- Sorveth Mind is local-first, optional and replaceable; all essential computing
  remains available with AI off.
- AI-built applications yield user-owned, exportable source, not an opaque rented
  package. Sandbox and explicit authorization are required for sensitive access.
- Sorveth Space remains recognizably usable without making AI a mandatory shell.
